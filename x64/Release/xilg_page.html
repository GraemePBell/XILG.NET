XILG: XML Image List Generator

Version 3
(pronounce it zilge - to rhyme with bilge)

The XILG program is intended to automate the process of building simple thumbnail web pages. It has a very simple and (I hope) self explanatory user interface.

Instructions

Page 1 - Choosing images and options

  • Choose the folder(s) with the images that you wish to convert from the tree view on the left. You may pick as many folders as you like, but only the images in the top level of each folder will be converted. Sub-folders are ignored, unless you check the "Automatically include subfolders" option.
  • You may choose to use your own CSS file, but it may result in less than optimal results.
  • At this point you can simply press the Build Website button and get a page with the default - but bare-bones - layout and styling. If you want to customise the page, then press the other buttons to check out the more advanced options available.

PAge 2 - The Basic Settings

  • Choose the destination folder, where you wish to create the new web page project. By default it goes to the current user's Documents folder.
  • The Page title is optional. It is the title that will be displayed by a web browser viewing the page. If you do not enter one, the default "User's Pictures" will be used.
  • The Project Title is required. It will be used to create the project folders under the destination folder you chose.
  • You may customise the size of the thumbnails, by selecting the Thumbnail Size 'radio button'. The default size of the thumbnails is 100px on the longest side. You may select others values for the longest side.
    Thumbnails are generated by scaling the original image to the requested size, preserving the apsect ratio.
  • If you have a lot of images, you may was to split them into multiple pages. If you check the "Multi-page output" option, you can specify how many thumbnails you want on each page. The program will then generate as many pages as necessary to hold all the thumbnails, and link them together with "Previous" and "Next" links.
  • The XHTML+XML/Only XHTML/Only XML option is for people who wish to look "under-the-hood" of the Web Site generation and not recommended for the average user to mess with.
  • The Choose title font and Choose caption font check boxes enable or disable the presence of the title and caption text on the generated pages. Clicking on the boxes will bring up the standard Windows Font dialog, where you can choose the font, size and colour of the title and caption text.

Page 3 - Advanced Background settings

  • Clicking with the Background colour box brings up the standard Windows colour picker dialog, where you can choose the background colour for the generated page. The default is grey.
  • Checking the Background Image box enables the use of a background image, which you may browse for, using the standard Windows file picker dialog. The image will be copied to the project folder and linked to from the generated page. The default is no background image.
  • If you have chosen a background image, you can specify how it should be displayed on the page. The default is to tile the image across and down the page. You may however choose to have it displayed only once, and aligned to your preference, or other options.
  • You can also specify a banner image to be displayed at the top of the page.

Page 4 - Watermark

  • XILG has the option to add a watermark to the full-sized images it displays on the generated page. This is a simple way to add a copyright notice to your images, without having to edit them in an image editor. The watermark is a small image that is overlaid on top of the full-sized image. You choose your own watermark image, it's position, what proportion of the original image will be overlaid and the opacity of the watermark.

Page 5 - Preview

  • A simple page where you can preview the settings you have chosen.

You are now ready to press the "Build Website" button.


What happens behind the curtains


On pressing the button, the program will now:

  1. Display this dialog

  2. Create the folder hierarchy based on your chosen destination folder

    • destination-folder\project-title
    • destination-folder\project-title\originals
    • destination-folder\project-title\thumbnails

  3. Create the following files in destination-folder\project-title

    • project-title.css
    • project-title.xsl


  4. Generate project-title.xml from the image files it finds in the folder given in the top edit box. The program recognises the following image types, by file extension:

    • JPG, JPEG.
    • GIF
    • TIF,TIFF
    • PNG
    • BMP


  5. Use the files generated in steps 2 & 3, and MSXML version3 to create the file

    • project-title.html

    in the folder

    • destination-folder\project-title


  6. Copy the image files from the original images folder into the folder as .jpg files, ready for use on the web site.

    destination-folder\project-title\images

    - optionally watermarking each image, in the process

  7. XILG then creates JPEG thumbnails of the images and writes them into the folder

    destination-folder\project-title\thumbnails

  8. If everything has gone well, the dialog change to:



  9. Closing that dialog will bring up this one:



  10. The "View Website" button will load the new project-title.html into your default Web Browser for viewing. If you wish, you can select any other browser you have installed, using the dropdown menu.

    The "Open button will open the project folder in Windows Explorer, so you can examine the files that have been generated and copy them to your web server as necessary.

    You can use the "FTP Upload" button to upload the generated files using the built-in ftp client. You will need to have an ftp server to upload to, and know the hostname, username and password for your account on that server. You can also specify a remote directory to upload to, if you don't want the files to go into the root of your account.

Notes

Browser Compatibility

The project-title.html uses the XHTML 1.1 standard, which should be accepted by all current browsers, since the first version was specified in 2001, updated in 2010 and the latest is from 2018.

The project-title.xml file may be viewed directly in an XSLT supporting browser. That's none currently, unless correctly served up by a web server. Use your favourite text editor.

This program is free. The source code is available on GitHub.
The original was built using the June 2002 Platform SDK from Microsoft and Visual C++ 6.0 Professional (Service Pack 5).
This version was built using Visual Studio 2022 Community Edition. It should compile and run on any Windows machine with the .NET Framework 4.0 or later installed, but I have only tested it on Windows 11. It may run on older versions of Windows, but I have not tested it on those. It will not run on non-Windows operating systems, since it uses Windows-specific APIs and features.
