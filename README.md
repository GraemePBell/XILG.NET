XILG - The XML Image List Generator is a  program designed to  automate the process of building simple thumbnail web pages. It has a simple and self explanatory user interface.

You choose images by folder, with the option to recurse down the filesystem. You can choose multiple folders. You set the text style and the backgound image and even have to option to watermark your images. You can choose to limit the number of images on a page and have multiple pages.

A few clicks and you have a fully generated web site with thumbnails, images and style sheets.
